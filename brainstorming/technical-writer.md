# Technical Writer

## Overview
A Technical Writer creates clear, accurate documentation that helps users and developers understand and use products, APIs, and systems. The work spans user guides, API references, tutorials, conceptual explanations, release notes, and developer portals. Modern technical writing increasingly follows a "docs-as-code" workflow, where documentation lives in version control alongside source code, is written in lightweight markup (Markdown/reStructuredText/AsciiDoc), and is built and published through CI/CD pipelines. Strong technical writers combine writing clarity with enough technical fluency to read code, run APIs, and collaborate closely with engineers.

## Required Skills
- Excellent written English: clarity, concision, structure, and audience awareness
- Information architecture and content organization (e.g., the Diataxis framework)
- Markdown, reStructuredText, or AsciiDoc authoring
- Docs-as-code workflow: Git, pull requests, static site generators (MkDocs, Docusaurus, Sphinx, Hugo)
- API documentation and OpenAPI/Swagger specifications
- Ability to read code samples and run basic commands/APIs to verify accuracy
- Editing, style guides, and consistent terminology management
- DITA and structured/topic-based authoring (for enterprise environments)
- Collaboration with engineers, product managers, and support teams
- Basic understanding of HTTP, JSON, CLIs, and the SDLC

## Sub-roles / Specializations
- API / Developer Documentation Writer
- Software / Product Documentation Writer
- Content Designer / UX Writer
- Documentation Engineer (docs tooling and pipelines)
- Information Architect
- Knowledge Base / Support Content Writer
- Documentation Lead / Content Strategy Manager

## Salary Trend
US (USD): entry ~$65,000; mid ~$85,000-$110,000; senior ~$120,000-$160,000+ (API/developer documentation specialists trend toward the higher end). India: roughly ₹5-18 LPA depending on technical depth and API documentation experience. 2025-26 demand: stable, with growing demand for developer-facing and API documentation writers who work in docs-as-code; generative AI is augmenting drafting but increasing the value of writers who can verify accuracy and own information architecture.

## Learning Roadmap
**Beginner:** Learn the fundamentals of technical writing, plain language, and audience analysis; complete the Google Technical Writing courses; practice with Markdown and basic Git.
**Intermediate:** Adopt a docs-as-code workflow with a static site generator, apply the Diataxis framework to structure content, and write an API reference from an OpenAPI specification.
**Advanced:** Own information architecture for a product, build and maintain documentation pipelines (CI/CD, linting, link checks), handle structured authoring/DITA where needed, and define style and content strategy.

## Notes for Course Generation
Structure a course as: writing clarity and audience analysis, Markdown and Git, docs-as-code with a static site generator, information architecture with Diataxis, and API reference writing from OpenAPI. Prerequisites are strong English writing ability and basic comfort with the command line. Capstone projects should include a complete docs-as-code site for a sample tool and a hand-authored API reference verified against a live or mocked endpoint.
