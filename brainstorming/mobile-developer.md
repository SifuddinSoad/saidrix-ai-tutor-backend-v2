# Mobile Developer

## Overview
A Mobile Developer designs and builds applications for iOS and Android devices, focusing on responsive touch interfaces, offline behavior, performance on constrained hardware, and platform-specific UX guidelines. Day-to-day work includes implementing UI screens and navigation, integrating with REST/GraphQL APIs, handling local storage and background tasks, managing app permissions, and shipping releases through the App Store and Google Play. They collaborate with designers, backend engineers, and QA, and monitor crashes and analytics post-release.

## Required Skills
- Native iOS: Swift, SwiftUI, UIKit, Xcode, Swift concurrency
- Native Android: Kotlin, Jetpack Compose, Android SDK, Android Studio, coroutines
- Cross-platform: Flutter (Dart) and/or React Native (JavaScript/TypeScript)
- Mobile architecture patterns: MVVM, MVI, clean architecture
- REST/GraphQL integration, JSON, networking, offline caching
- Local persistence: SQLite, Room, Core Data, Realm
- App lifecycle, navigation, state management, push notifications
- Performance profiling, memory management, battery/network efficiency
- App Store / Play Store release process, code signing, CI/CD (Fastlane)
- Soft skills: UX sensitivity, attention to platform guidelines, debugging discipline

## Sub-roles / Specializations
- iOS Developer (Swift/SwiftUI)
- Android Developer (Kotlin/Compose)
- Cross-platform Developer (Flutter / React Native)
- Mobile Architect
- Mobile Performance / Reliability Engineer
- Mobile DevOps / Release Engineer
- AR/Mobile graphics specialist (ARKit/ARCore)

## Salary Trend
US: entry ~$85k–$110k; mid ~$120k–$145k; senior ~$165k–$230k+ (higher with deep iOS/Android specialization at large firms). India: absolute USD figures typically 70–85% lower at comparable levels, with senior roles at top product/MNC companies closing much of the gap. 2025–2026 outlook: steady demand, with cross-platform (Flutter/React Native) widening the entry market and strong native depth (Swift/Kotlin) commanding a premium for performance-critical and large-scale apps.

## Learning Roadmap
**Beginner:** Pick one platform; learn its language (Swift or Kotlin) and UI toolkit (SwiftUI or Jetpack Compose). Build simple single-screen apps, handle user input, and learn the IDE and emulator workflow.
**Intermediate:** Add navigation, networking with a REST API, local persistence, state management, and architecture patterns (MVVM). Publish a small app to TestFlight or an internal track and learn debugging/profiling tools.
**Advanced:** Master performance and memory optimization, offline-first sync, push notifications, modularization, automated testing, CI/CD with Fastlane, and store release management. Optionally add a cross-platform stack.

## Notes for Course Generation
Have learners commit to one platform first (recommend native Kotlin/Android or Swift/iOS) before introducing cross-platform, since platform fundamentals transfer better than the reverse. Structure modules as: language basics → declarative UI → navigation → networking + persistence → architecture → release. Prerequisites: basic programming and OOP. Project ideas: a notes app with local storage, a weather app consuming a public API, and a capstone app with auth, offline caching, push notifications, and a published store/TestFlight build.
