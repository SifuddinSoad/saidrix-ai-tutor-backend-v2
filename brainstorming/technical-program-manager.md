# Technical Program Manager

## Overview
A Technical Program Manager (TPM) drives the execution of complex, cross-team technical initiatives from planning to delivery. TPMs sit between engineering, product, and leadership, owning program structure: scoping, dependency mapping, risk management, timeline tracking, and clear communication of status and trade-offs. Unlike a pure project manager, a TPM has enough technical fluency to understand architecture, interrogate engineering estimates, and make informed prioritization calls. The best TPMs reduce organizational friction — surfacing risks early, unblocking teams, and keeping multiple workstreams aligned toward a shared launch.

## Required Skills
- Cross-team program delivery: planning, scoping, milestone tracking
- Technical fluency: systems architecture, APIs, infrastructure, ability to read design docs
- Dependency and stakeholder management across multiple teams
- Risk management: identification, mitigation, contingency planning
- Agile and delivery methodologies: Scrum, Kanban, release management
- Communication: status reporting, executive updates, driving alignment
- Prioritization and trade-off negotiation
- Metrics and operational rigor (burndown, velocity, launch readiness)

## Sub-roles / Specializations
- Infrastructure / Platform TPM
- Product-facing TPM (feature and launch programs)
- Data / ML TPM
- Security or Compliance Program Manager
- Release / Launch Program Manager
- Senior / Principal TPM and Director of Technical Program Management (leadership track)

## Salary Trend
US (USD): entry ~$110,000; mid ~$150,000–$185,000; senior/principal ~$210,000–$330,000+ (large tech firms higher with equity). India note: compensation typically ranges ₹15–45 LPA depending on experience and company tier. 2025–26 demand: strong, especially for TPMs with platform, data/ML, or security depth; companies increasingly value technical credibility plus program rigor for large cross-org initiatives.

## Learning Roadmap
**Beginner:** Learn program/project management fundamentals, agile (Scrum/Kanban), and basic software architecture concepts. Take the Google Project Management Certificate and practice building a project plan with milestones and risks.
**Intermediate:** Manage a real multi-team initiative: map dependencies, run standups and status reporting, track risks, and negotiate scope. Deepen technical literacy (system design basics, APIs). Study "The Manager's Path" and Agile practices.
**Advanced:** Drive large cross-org programs, establish program governance and operating cadences, influence technical strategy and trade-offs, and mentor other TPMs. Develop a domain specialization (infra, ML, security).

## Notes for Course Generation
Build the course in modules: program management foundations, agile and delivery methodologies, technical fluency for TPMs (architecture, APIs, system design basics), dependency and risk management, and communication/program governance. Prerequisites: comfort with software concepts and basic project planning; deep coding is not required but technical curiosity is essential. Include hands-on projects: a full program plan with dependency map and risk register, a simulated cross-team status readout, and a capstone case study managing a multi-team launch with trade-off decisions.
