# Game Developer

## Overview
A Game Developer builds interactive games and real-time simulations, implementing gameplay mechanics, physics, rendering, input, audio, and UI within a game engine. Day-to-day work includes writing gameplay and systems code, integrating art and audio assets, profiling and optimizing frame performance, fixing bugs, and iterating tightly with designers and artists. Work spans console, PC, mobile, and web, and ranges from large studios with specialized roles to small indie teams where one person covers many disciplines.

## Required Skills
- Languages: C++ (engine/AAA) and C# (Unity); some studios use Lua, Python (tooling), or Rust
- Engines: Unity, Unreal Engine; awareness of Godot
- Math & physics: linear algebra, vectors/matrices, quaternions, trigonometry, collision and rigid-body physics
- Graphics fundamentals: rendering pipeline, shaders (HLSL/GLSL), lighting, animation
- Gameplay systems: state machines, ECS, AI (pathfinding, behavior trees), input handling
- Performance optimization: frame budgets, profiling, memory management, multithreading
- Version control for binary assets (Git LFS, Perforce)
- Tools: debuggers, profilers, build pipelines, asset pipelines
- Soft skills: iteration mindset, collaboration with artists/designers, "fun"-focused problem solving

## Salary Trend
US: entry ~$70k–$95k; mid ~$95k–$130k; senior ~$140k–$200k+ (engine/graphics and AAA specialists at the top; salaries generally trail comparable web/backend roles). India: absolute USD figures typically 70–85% lower at comparable levels, with senior roles at established studios narrowing the gap. 2025–2026 outlook: competitive market with cyclical studio hiring; durable demand for engine, graphics, and multiplayer specialists, plus growth in mobile, live-service, and indie/tools roles.

## Learning Roadmap
**Beginner:** Learn programming fundamentals in C# (Unity) or C++; complete an engine's official beginner path; build small complete games (Pong, Breakout, a 2D platformer) to learn the game loop, input, and collision.
**Intermediate:** Study game math and physics, gameplay architecture (state machines, ECS), basic AI, UI, audio, and asset pipelines. Ship a polished small game and learn profiling and source control with large assets.
**Advanced:** Specialize: graphics/shaders, engine systems, networking/multiplayer, or AI. Master performance optimization within frame budgets, multithreading, and shipping/porting to a target platform.

## Notes for Course Generation
Make the course intensely project-based: every module should end with a runnable game or mechanic, because games are learned by building them. Prerequisites: programming basics and comfort with an IDE; gate math-heavy modules (vectors, physics) behind a working 2D game. Sequence: engine basics → 2D complete game → game math/physics → 3D and a chosen specialization (graphics/AI/networking) → optimization and shipping. Project ideas: 2D platformer, a physics puzzle game, and a capstone 3D game with AI enemies and a profiled, optimized build.
