# Systems Administrator

## Overview
A Systems Administrator (sysadmin) installs, configures, maintains, and secures an organization's servers, operating systems, and core IT services. Responsibilities include user and access management, patching and updates, backups and disaster recovery, performance monitoring, and troubleshooting hardware and software issues across Linux and Windows environments. Sysadmins keep day-to-day infrastructure running and reliable, often serving as the first line of defense for uptime and security. The role increasingly overlaps with automation and cloud, making scripting and infrastructure-as-code valuable adjacent skills.

## Required Skills
- Linux administration (users, permissions, services, systemd, package management)
- Windows Server administration and Active Directory (users, group policy, DNS, DHCP)
- Networking fundamentals (TCP/IP, DNS, DHCP, firewalls, VPN)
- Scripting and automation (Bash, PowerShell, basic Python)
- Backup, restore, and disaster recovery planning
- Patch management, hardening, and security best practices
- Virtualization and basic cloud (VMware/Hyper-V, AWS/Azure fundamentals)
- Monitoring, logging, and troubleshooting methodology
- Documentation, ticketing, and incident handling

## Sub-roles / Specializations
- Linux Systems Administrator
- Windows / Active Directory Administrator
- Virtualization Administrator (VMware/Hyper-V)
- Storage / Backup Administrator
- Cloud Systems Administrator (hybrid environments)
- IT Operations / Infrastructure Administrator

## Salary Trend
US (USD, base): entry ~$60,000; mid ~$75,000-$95,000; senior ~$100,000-$130,000+ (lead/infrastructure roles higher). India note: roughly INR 4-14 LPA depending on experience, OS specialization, and employer tier. 2025-26 demand: steady, with the role evolving toward automation and cloud; sysadmins who add scripting, IaC, and cloud skills move into DevOps/cloud/SRE tracks and command meaningfully higher pay.

## Learning Roadmap
**Beginner:** Learn the Linux command line and core administration tasks; install and manage a Windows Server with Active Directory; understand TCP/IP, DNS, and DHCP; practice user and permission management.
**Intermediate:** Automate routine tasks with Bash and PowerShell; set up backups and a recovery plan; configure monitoring and centralized logging; learn virtualization and a cloud provider's fundamentals; harden and patch systems.
**Advanced:** Build infrastructure-as-code and configuration management; design highly available and disaster-recoverable systems; manage hybrid cloud environments; lead security hardening and compliance; pursue Linux/Server certifications.

## Notes for Course Generation
Build the course around hands-on labs on both Linux and Windows Server, with modules for OS administration, Active Directory, networking services, backup/DR, security hardening, and automation scripting. Prerequisites are basic computer literacy and networking concepts; projects should include standing up a small multi-server environment with AD, automated backups, and monitoring. Reference certifications such as CompTIA Server+, CompTIA Linux+, and Red Hat RHCSA to anchor outcomes.
