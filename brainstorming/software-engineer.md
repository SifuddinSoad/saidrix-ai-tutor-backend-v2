# Software Engineer

## Overview
A Software Engineer designs, builds, tests, and maintains software systems by applying engineering principles to the full development lifecycle. Day-to-day work involves writing and reviewing code, designing APIs and data models, debugging production issues, collaborating in code reviews, and participating in architecture discussions and agile ceremonies. The role is general-purpose and often backend-leaning, spanning services, databases, and infrastructure.

## Required Skills
- Languages: Python, Java, Go, C#, TypeScript/JavaScript, or C++ (typically 1-2 deeply)
- Data structures, algorithms, and complexity analysis
- Databases: SQL (PostgreSQL/MySQL) and at least one NoSQL store (Redis, MongoDB)
- API design: REST and gRPC; basic understanding of GraphQL
- Version control with Git and trunk/branch workflows
- Testing: unit, integration, and end-to-end; TDD fundamentals
- System design and distributed systems basics (caching, queues, load balancing)
- CI/CD, containers (Docker), and basic cloud (AWS/GCP/Azure)
- Operating systems, networking, and concurrency fundamentals
- Soft skills: clear written communication, code review etiquette, problem decomposition, ownership

## Sub-roles / Specializations
- Backend Engineer
- Platform / Infrastructure Engineer
- Site Reliability Engineer (SRE)
- DevOps Engineer
- Data Engineer
- Machine Learning Engineer
- Security Engineer
- Engineering Manager / Tech Lead (track shift)

## Salary Trend
- US (USD): Entry ~$80k-$120k; Mid ~$120k-$170k; Senior ~$170k-$250k+ (higher at large tech firms with equity).
- India (₹ LPA): Entry ~₹6-12 LPA; Mid ~₹15-30 LPA; Senior ~₹35-70+ LPA at top product companies.
- 2025-2026 outlook: Steady-to-strong demand; growth concentrated in AI/ML-adjacent, cloud, and platform roles. Routine CRUD work increasingly augmented by AI tooling, raising the bar for system design and judgment.

## Learning Roadmap
**Beginner:** Learn one language well (Python or Java), core data structures and algorithms, Git, basic SQL, and how to build and test a small CLI or web service.
**Intermediate:** Build REST APIs with a real database, add authentication, write automated tests, learn Docker, deploy to a cloud provider, and study system design basics (caching, queues, scaling).
**Advanced:** Design distributed systems, master observability and reliability (SLOs, tracing), contribute to large codebases, study performance tuning, and develop architecture and mentoring skills.

## Notes for Course Generation
Structure the course as a progression from programming fundamentals to system design, since "software engineer" is broad. An AI tutor should anchor each module around a buildable project (CLI tool, then API, then a small distributed system) and weave in testing and Git from the start. Emphasize judgment and trade-off reasoning over memorization, especially as AI tooling handles boilerplate.
