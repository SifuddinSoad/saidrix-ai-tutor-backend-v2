# Blockchain / Web3 Developer

## Overview
A Blockchain / Web3 Developer builds decentralized applications (dApps), smart contracts, and protocol infrastructure on networks like Ethereum and EVM-compatible chains. The role spans on-chain logic (Solidity/Rust), off-chain integration (wallets, RPC, indexers), and a strong emphasis on security because deployed contracts are immutable and handle real value. Specialists range from application developers to protocol and security engineers.

## Required Skills
- Blockchain fundamentals: blocks, consensus, gas, accounts, transactions, EVM
- Smart contract languages: Solidity (Ethereum/EVM), optionally Rust (Solana, Polkadot)
- Development frameworks: Hardhat, Foundry, Truffle
- Web3 client libraries: ethers.js, viem, web3.js, wagmi
- Frontend skills (JavaScript/TypeScript, React) for dApp interfaces
- Wallet integration (MetaMask, WalletConnect) and RPC providers
- Smart contract security: reentrancy, access control, integer issues, auditing mindset
- Testing and fuzzing on-chain logic (Foundry tests, Hardhat)
- Token standards (ERC-20, ERC-721, ERC-1155) and common patterns
- Familiarity with L2s/rollups, oracles, and indexing (The Graph)

## Sub-roles / Specializations
- Smart Contract Developer (Solidity/EVM)
- dApp / Frontend Web3 Developer
- Protocol / Core Blockchain Engineer
- Smart Contract Security Auditor
- DeFi Engineer
- NFT / Gaming (GameFi) Developer
- Infrastructure / Node & Tooling Engineer

## Salary Trend
US (USD): entry ~$90K–$120K, mid ~$120K–$170K, senior/protocol/security ~$170K–$250K+ (top auditors and core protocol roles can exceed this). India (₹ LPA): entry ~₹6–12 LPA, mid ~₹15–30 LPA, senior ~₹30–60+ LPA. 2025–2026 demand is cyclical but recovering, concentrated in security/auditing, L2 scaling, stablecoins/payments, and real-world-asset tokenization; security expertise commands the strongest premium.

## Learning Roadmap
**Beginner:** Learn blockchain and Ethereum fundamentals (accounts, gas, transactions). Complete an interactive Solidity course and write/deploy simple contracts on a testnet.

**Intermediate:** Build full dApps with Hardhat or Foundry plus a React frontend using ethers.js/viem and wallet integration. Write thorough tests, work with token standards, and deploy to a public testnet.

**Advanced:** Study smart contract security and common vulnerability classes, fuzz/invariant testing with Foundry, gas optimization, L2 deployment, oracles/indexers, and audit-grade code review.

## Notes for Course Generation
Center the course on shipping and securing a real dApp end-to-end (contract + tests + frontend + testnet deploy). Treat security as a first-class, recurring theme rather than a single module, given immutability and financial risk. Use Solidity/EVM as the default track with Foundry for testing, and clearly flag that mainnet deployment involves real funds and audits.
