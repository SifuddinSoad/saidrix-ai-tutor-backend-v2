# Penetration Tester / Ethical Hacker

## Overview
A Penetration Tester (Ethical Hacker) is hired to legally and methodically attack an organization's systems, networks, web applications, and people in order to find exploitable weaknesses before malicious actors do. The role combines deep technical offensive skills with disciplined methodology and high-quality reporting: scoping engagements, performing reconnaissance, identifying and exploiting vulnerabilities, escalating privileges, demonstrating business impact, and delivering actionable remediation guidance. Red teaming extends this into stealthy, objective-driven adversary emulation that also tests an organization's detection and response. Strong penetration testers think like attackers but communicate like consultants. The career path leads toward senior red teaming, exploit development, application security, and offensive security leadership.

## Required Skills
- Networking and protocols (TCP/IP, DNS, SMB, HTTP/S, TLS)
- Linux and Windows administration and command-line proficiency
- Web application security (OWASP Top Ten, injection, auth flaws, SSRF, deserialization)
- Vulnerability identification and manual exploitation (not just automated scanning)
- Privilege escalation and post-exploitation (Windows/Linux/Active Directory)
- Tooling mastery: Burp Suite, Metasploit, Nmap, Wireshark, BloodHound, Impacket, Hashcat
- Scripting and tool development (Python, Bash, PowerShell) and basic exploit modification
- Report writing and clear communication of risk and remediation to technical and business audiences

## Sub-roles / Specializations

Offensive security talent remains scarce; OSCP remains the strongest hiring signal, and demand for penetration testers and red teamers continues to rise through 2025–2026, driven by compliance requirements, cloud adoption, and adversary sophistication.

## Learning Roadmap
**Beginner:** Build networking, Linux, and scripting fundamentals. Learn web fundamentals and the OWASP Top Ten. Practice on free platforms (TryHackMe beginner/offensive paths, PortSwigger Web Security Academy). Optionally earn **CompTIA Security+ (SY0-701)** for baseline credibility.

**Intermediate:** Develop hands-on exploitation skills against intentionally vulnerable machines (Hack The Box, VulnHub, PentesterLab). Learn Active Directory attacks and pivoting. Earn **CompTIA PenTest+ (PT0-003)** or INE eJPT, and progress toward the **OSCP (OffSec PEN-200)** — the industry-standard practical penetration testing certification — and/or **CEH v13** or the **PNPT** (Practical Network Penetration Tester).

**Advanced:** Specialize in red teaming, cloud, or exploit development. Pursue advanced credentials such as OSEP, OSWE, or OSED, build C2 tradecraft and custom tooling mapped to MITRE ATT&CK, and contribute original research, tooling, or CVEs to build a professional reputation.

## Notes for Course Generation
Sequence the course methodology-first: networking/Linux/scripting foundations, the penetration testing methodology (recon → exploitation → post-exploitation → reporting), web application exploitation, network and Active Directory attacks, privilege escalation, and professional reporting. Prerequisites are solid networking knowledge, Linux comfort, and basic scripting; this is not a true zero-IT-background track. Pair every offensive technique with a defensive/remediation note and an OWASP or MITRE ATT&CK mapping. Include hands-on lab projects such as a full scoped pentest of a vulnerable VM, an OWASP-based web app exploitation challenge, and an Active Directory attack chain culminating in a professional findings report.
