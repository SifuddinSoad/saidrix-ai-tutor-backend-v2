# Full-Stack Developer

## Overview
A Full-Stack Developer builds complete web applications, owning both the client-facing interface and the server-side logic, databases, and deployment. Day-to-day work spans UI components, API design, data modeling, authentication, and shipping features end-to-end, often in startups or small teams where versatility is valued. They balance breadth across the stack with enough depth to make sound architectural decisions.

## Required Skills
- Frontend: HTML, CSS, JavaScript/TypeScript, React (or Vue/Angular), responsive design
- Backend: Node.js/Express/NestJS, or Python/Django/FastAPI, or similar
- Databases: SQL (PostgreSQL/MySQL) and a NoSQL store; ORMs (Prisma, SQLAlchemy)
- API design: REST and GraphQL; authentication (JWT, OAuth2, sessions)
- Full-stack frameworks: Next.js, Remix, or SvelteKit
- DevOps basics: Docker, CI/CD, deploying to Vercel/Render/AWS
- Testing across the stack: unit, integration, end-to-end
- Version control, Git workflows, and code review
- Soft skills: prioritization, product thinking, communication, autonomy

## Sub-roles / Specializations
- MERN / MEAN / Next.js Stack Developer
- Frontend-leaning Full-Stack Developer
- Backend-leaning Full-Stack Developer
- Startup Generalist / Founding Engineer
- Full-Stack + DevOps (T-shaped)
- JAMstack / Serverless Developer

## Salary Trend
- US (USD): Entry ~$75k-$110k; Mid ~$110k-$160k; Senior ~$160k-$225k+.
- India (₹ LPA): Entry ~₹5-11 LPA; Mid ~₹14-28 LPA; Senior ~₹30-60+ LPA.
- 2025-2026 outlook: High demand, particularly in startups and product teams; AI coding assistants make full-stack breadth more attainable, raising the premium on those who can architect and integrate systems well.

## Learning Roadmap
**Beginner:** Learn HTML/CSS/JavaScript and one backend language; build a simple full-stack CRUD app (frontend + API + database) and use Git.
**Intermediate:** Adopt React + TypeScript and a full-stack framework (Next.js), add authentication, automated tests, and deploy to the cloud; learn database design and API patterns.
**Advanced:** Master end-to-end architecture, performance, caching, CI/CD, serverless or containerized deployment, and lead feature delivery from design to production.

## Notes for Course Generation
Center the course on shipping one real product end-to-end, growing it module by module (UI, API, database, auth, deployment) so learners experience the full lifecycle. An AI tutor should explicitly teach when to go deep versus stay broad, and highlight integration points (auth flows, API contracts, deploy pipelines) where full-stack developers add the most value. Use Full Stack Open or The Odin Project structure as a proven scaffold.
