# QA / Test Automation Engineer

## Overview
A QA / Test Automation Engineer designs, builds, and maintains automated test suites that validate software quality across web, API, and mobile layers. The role blends software engineering with quality strategy, shifting testing earlier in the development lifecycle ("shift-left") and integrating checks into CI/CD pipelines. Modern automation engineers are expected to write production-grade test code, not just click through UIs.

## Required Skills
- Strong programming fundamentals in at least one language (JavaScript/TypeScript, Python, Java, or C#)
- UI automation frameworks: Playwright, Selenium WebDriver, Cypress
- API testing: Postman, REST Assured, supertest, contract testing (Pact)
- Test design techniques: equivalence partitioning, boundary value analysis, risk-based testing
- CI/CD integration: GitHub Actions, GitLab CI, Jenkins
- Version control with Git and code-review workflows
- Debugging, flaky-test triage, and test reporting (Allure, JUnit XML)
- Understanding of HTTP, browsers, DOM, selectors, and async behavior
- Basic performance and load testing awareness (k6, JMeter)
- Bug reporting, test planning, and clear written communication

## Sub-roles / Specializations
- UI / End-to-End Automation Engineer
- API / Backend Test Engineer
- Mobile Automation Engineer (Appium, Espresso, XCUITest)
- Performance / Load Test Engineer
- SDET (Software Development Engineer in Test)
- Quality / Test Architect
- Test Infrastructure / CI Engineer

## Salary Trend
US (USD): entry ~$70K–$95K, mid ~$95K–$130K, senior/SDET ~$130K–$185K+. India (₹ LPA): entry ~₹4–8 LPA, mid ~₹9–18 LPA, senior/SDET ~₹20–40+ LPA. 2025–2026 demand is steady-to-strong: SDET and automation-heavy roles remain in demand while pure manual QA roles decline; AI-assisted test generation is reshaping but not eliminating the role, raising the bar toward coding proficiency.

## Learning Roadmap
**Beginner:** Learn manual testing concepts and test case design. Pick one language (JavaScript or Python). Learn Git, the browser DevTools, HTTP basics, and write your first UI tests with Playwright or Cypress.

**Intermediate:** Build maintainable frameworks (Page Object Model, fixtures, data-driven tests). Add API testing, integrate suites into CI (GitHub Actions), and learn debugging flaky tests, reporting, and parallel execution.

**Advanced:** Design scalable test architecture, contract testing, performance testing, cross-browser/device grids, observability for tests, and quality strategy across teams. Mentor and own the test pyramid.

## Notes for Course Generation
Structure the course around a hands-on project: automate a real sample app from UI through API into CI. Emphasize coding fundamentals early since modern QA roles require it, and include flaky-test triage and CI integration as dedicated modules. Use Playwright as the primary UI tool given its momentum, with Selenium as a transferable industry-standard reference.
