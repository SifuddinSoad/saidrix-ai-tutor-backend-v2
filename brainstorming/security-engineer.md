# Security Engineer

## Overview
A Security Engineer designs, builds, and maintains the systems and controls that keep an organization secure. Rather than primarily monitoring or attacking, this role is constructive: defining secure architectures, hardening cloud and on-premises infrastructure, implementing identity and access management, applying cryptography correctly, embedding security into the software development lifecycle (DevSecOps), and automating defenses at scale. Security Engineers bridge software engineering and security, requiring strong coding ability alongside deep security knowledge. The role offers a high-growth, high-compensation trajectory toward staff/principal engineering, security architecture, and engineering leadership.

## Required Skills
- Secure system and network architecture design
- Cloud security (AWS/Azure/GCP — IAM, network security, key management, logging)
- Identity and access management (authentication, authorization, federation, least privilege)
- Applied cryptography (TLS, key management, hashing, encryption at rest/in transit)
- Application security and secure coding (OWASP, threat modeling, code review)
- DevSecOps and automation (CI/CD security, IaC scanning, policy as code)
- Strong programming/scripting (Python, Go, Bash) and systems knowledge
- Infrastructure hardening, logging/monitoring design, and incident-resilient architecture

## Sub-roles / Specializations
- Cloud Security Engineer
- Application Security (AppSec) Engineer
- DevSecOps / Platform Security Engineer
- Identity and Access Management (IAM) Engineer
- Security Architect
- Cryptography / Product Security Engineer

## Learning Roadmap
**Beginner:** Build software engineering and networking fundamentals plus security basics. Earn **CompTIA Security+ (SY0-701)**. Learn one cloud provider's core services and the OWASP Top Ten. Follow the roadmap.sh cybersecurity track for orientation.

**Intermediate:** Go deep on cloud security and IAM (e.g., AWS Security Specialty or equivalent Azure/GCP credentials), threat modeling, and secure CI/CD pipelines. Study applied cryptography and secure coding. Build automation projects (IaC scanning, policy as code).

**Advanced:** Master security architecture, zero-trust design, and large-scale DevSecOps. Pursue **CISSP** for breadth and architecture credibility, and/or specialized credentials such as CCSP or OSCP for offensive depth. Read foundational engineering texts and contribute to internal security tooling/standards.

## Notes for Course Generation
Organize modules as: secure architecture principles, cloud security and IAM, applied cryptography, application security and threat modeling, DevSecOps and automation, and security monitoring/resilience design. Prerequisites are programming/scripting ability and networking fundamentals — this track assumes a software or systems background. Include hands-on lab projects such as hardening a cloud account with least-privilege IAM, building a secure CI/CD pipeline with automated SAST/IaC scanning, and producing a threat model with mitigations for a sample application.
