# Frontend Developer

## Overview
A Frontend Developer builds the user-facing part of web applications, translating designs into responsive, accessible, and performant interfaces. Day-to-day work includes implementing UI components, managing client-side state, integrating with APIs, optimizing rendering and load performance, and ensuring cross-browser and accessibility compliance. They collaborate closely with designers, product managers, and backend engineers.

## Required Skills
- Core: HTML5, CSS3, modern JavaScript (ES2015+), TypeScript
- Frameworks: React (most in-demand), plus familiarity with Vue, Angular, or Svelte
- State management: Redux/Zustand/React Query or framework equivalents
- Styling: Flexbox, Grid, CSS-in-JS, Tailwind CSS, responsive design
- Build tooling: Vite, Webpack, npm/pnpm, ESLint, Prettier
- Web fundamentals: the DOM, browser rendering, the event loop, HTTP
- Accessibility (WCAG/ARIA) and semantic markup
- Performance: Core Web Vitals, lazy loading, bundle optimization
- Testing: Jest/Vitest, React Testing Library, Playwright/Cypress
- Soft skills: design empathy, attention to detail, communication with non-technical stakeholders

## Sub-roles / Specializations
- React / Vue / Angular Specialist
- UI Engineer (design-systems focused)
- Web Performance Engineer
- Accessibility (a11y) Engineer
- Frontend Platform / Tooling Engineer
- Creative / Interactive Developer (WebGL, canvas, animation)
- Frontend-leaning Full-Stack Developer

## Salary Trend
- US (USD): Entry ~$70k-$105k; Mid ~$105k-$150k; Senior ~$150k-$210k+.
- India (₹ LPA): Entry ~₹5-10 LPA; Mid ~₹12-25 LPA; Senior ~₹28-55+ LPA.
- 2025-2026 outlook: Solid demand, with strongest growth for engineers who combine React/TypeScript depth with performance, accessibility, and design-system skills. AI tooling speeds up scaffolding, increasing emphasis on architecture and UX quality.

## Learning Roadmap
**Beginner:** Master HTML, CSS (Flexbox/Grid), and JavaScript fundamentals; build static and interactive pages without frameworks; learn Git and browser dev tools.
**Intermediate:** Learn React and TypeScript, component architecture, state management, API integration, responsive design, and basic testing; deploy projects to Vercel/Netlify.
**Advanced:** Master performance optimization (Core Web Vitals), accessibility, design systems, SSR/SSG with Next.js, advanced testing, and frontend architecture at scale.

## Notes for Course Generation
Build the course project-first: ship a small app early using only HTML/CSS/JS, then refactor it into React/TypeScript so learners feel why frameworks exist. An AI tutor should integrate accessibility and performance as recurring themes rather than a final afterthought, and use live browser-based exercises. End with a deployable portfolio project demonstrating a design system and Core Web Vitals optimization.
