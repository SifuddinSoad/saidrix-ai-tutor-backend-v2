# Data Analyst

## Overview
A Data Analyst turns raw data into actionable insight that supports business decisions. Day-to-day work involves collecting, cleaning, and validating data, writing SQL queries, building dashboards, performing exploratory analysis in spreadsheets or Python/R, and presenting findings to stakeholders. The role sits between the business and the data: analysts translate ambiguous questions ("why did churn rise last quarter?") into measurable metrics, queries, and visualizations people can act on. It is one of the most common entry points into the broader data field and emphasizes clarity of communication as much as technical skill.

## Required Skills
- **SQL** — joins, aggregation, window functions, CTEs (the single most important skill)
- **Spreadsheets** — advanced Excel/Google Sheets: pivot tables, lookups, formulas, light modeling
- **BI / visualization tools** — Power BI, Tableau, or Looker for dashboards and self-serve reporting
- **Statistics fundamentals** — descriptive stats, distributions, correlation, hypothesis testing, A/B test reading
- **Python (or R)** — pandas, NumPy, matplotlib/seaborn for analysis beyond a spreadsheet
- **Data cleaning & wrangling** — missing values, deduplication, type coercion, outliers
- **Business acumen** — KPIs, funnels, cohorts, and understanding the domain
- **Communication & data storytelling** — narrative structure, chart choice, presenting to non-technical stakeholders

## Sub-roles / Specializations
- Product Analyst (funnels, retention, feature adoption, experimentation)
- Marketing / Growth Analyst (attribution, campaign ROI, channel performance)
- Financial / Operations Analyst (budgeting, forecasting, efficiency metrics)
- Healthcare / Risk / People (HR) Analyst (domain-specialized analytics)
- BI-focused Analyst (heavier dashboard and data-modeling focus)

## Salary Trend
US (USD): entry ~$70k; mid ~$85k–$95k; senior ~$110k+ (higher in tech hubs and for product/finance specializations). India: typically ₹5–12 LPA depending on city, domain, and tooling depth. 2025–26 demand: steady and broad — analysts remain among the highest-volume data hires, though employers increasingly expect SQL plus a BI tool plus light Python/AI-tool fluency rather than spreadsheet-only profiles.

## Learning Roadmap
**Beginner:** Excel/Sheets fundamentals; SQL basics (SELECT, WHERE, GROUP BY, JOIN); descriptive statistics; build first chart and a simple dashboard; understand the analytics workflow (question → data → analysis → insight).
**Intermediate:** Window functions and subqueries; Python with pandas for cleaning and EDA; a BI tool end-to-end (Power BI or Tableau); A/B test interpretation; cohort and funnel analysis.
**Advanced:** Data modeling for reporting; advanced DAX/LookML; statistical rigor (confidence intervals, regression); automating reports; a portfolio of analyses with clear business narratives; executive-level communication.

## Notes for Course Generation
Build modules in this order: spreadsheets and data thinking, SQL (basic then window functions), statistics for analysts, Python/pandas, a BI tool, and data storytelling. Prerequisites are minimal — basic computer literacy and comfort with numbers. Each module should end with a hands-on project on a realistic public dataset (e.g., e-commerce or web-analytics), culminating in a capstone dashboard plus a written insight report so learners finish with a portfolio.
