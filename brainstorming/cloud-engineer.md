# Cloud Engineer

## Overview
A Cloud Engineer designs, builds, and operates infrastructure and services on public cloud platforms such as AWS, Azure, or Google Cloud. The role covers provisioning compute, networking, storage, and identity; automating infrastructure with code; securing workloads; and optimizing for performance, reliability, and cost. Cloud Engineers translate application requirements into well-architected, scalable cloud designs and operate them through their lifecycle. They work closely with developers, security, and operations teams and are often the primary owners of an organization's cloud accounts, landing zones, and guardrails.

## Required Skills
- Deep knowledge of at least one major cloud (AWS, Azure, or GCP): compute, storage, databases, serverless
- Cloud networking (VPC/VNet, subnets, routing, load balancers, DNS, VPN/peering)
- Identity and access management (IAM), least-privilege design, and cloud security posture
- Infrastructure as Code (Terraform, CloudFormation/Bicep) and automation scripting
- Containers and orchestration (Docker, Kubernetes/EKS/AKS/GKE)
- Cost management, billing, budgeting, and FinOps practices
- Monitoring, logging, and observability with native cloud tooling
- Linux fundamentals, scripting (Bash/Python), and CI/CD basics
- High availability, disaster recovery, and backup design

## Sub-roles / Specializations
- Cloud Infrastructure Engineer (landing zones, networking, IaC)
- Cloud Security Engineer (IAM, posture management, compliance)
- Cloud Architect (solution and well-architected design)
- FinOps / Cloud Cost Engineer
- Cloud Network Engineer
- Cloud Migration / Modernization Engineer

## Salary Trend
US (USD, base): entry ~$100,000; mid ~$135,000-$165,000; senior ~$185,000-$260,000+ (cloud architects and large-tech roles higher). India note: roughly INR 6-28 LPA depending on experience, cloud certifications, and employer tier. 2025-26 demand: very strong as organizations continue migrating and modernizing; multi-cloud, cloud security, FinOps, and AI/ML platform skills are in highest demand, and recognized certifications materially raise hireability and pay.

## Learning Roadmap
**Beginner:** Learn cloud fundamentals and core services of one provider (compute, storage, networking, IAM); set up a free-tier account and deploy a basic web app; learn Linux and basic scripting.
**Intermediate:** Automate infrastructure with Terraform; design VPC networking and secure IAM; deploy containers to a managed Kubernetes service; add monitoring, logging, and cost budgets; pursue an associate-level certification.
**Advanced:** Design multi-account/multi-region landing zones with guardrails; implement well-architected reviews, disaster recovery, and FinOps optimization; integrate CI/CD and policy-as-code; explore multi-cloud and cloud security at scale.

## Notes for Course Generation
Organize the course around one primary cloud provider with modules for fundamentals, networking, IAM/security, IaC with Terraform, containers, and cost/observability, plus an optional multi-cloud comparison. Prerequisites are basic networking and command-line familiarity; capstone projects should provision a secure, monitored, cost-bounded multi-tier application via IaC. Map the path to certifications such as AWS Solutions Architect Associate (SAA-C03), Microsoft Azure Administrator (AZ-104), and Google Associate Cloud Engineer (ACE).
