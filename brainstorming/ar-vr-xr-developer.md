# AR / VR / XR Developer

## Overview
An AR/VR/XR Developer builds immersive 3D applications spanning augmented reality (overlays on the real world), virtual reality (fully simulated environments), and the broader spectrum of extended reality. The role combines real-time 3D engine work (Unity or Unreal), spatial interaction design, and platform-specific SDKs for headsets and mobile devices. Strong performance optimization skills are critical because immersive apps must hold stable high frame rates to avoid user discomfort.

## Required Skills
- 3D math fundamentals: vectors, matrices, transforms, quaternions
- A real-time engine: Unity (C#) or Unreal Engine (C++/Blueprints)
- XR SDKs and standards: OpenXR, Unity XR Interaction Toolkit, Meta/Quest SDK, ARKit, ARCore
- 3D asset pipeline: meshes, materials, shaders, lighting, optimization (LOD, draw calls)
- Spatial interaction and UX: hand tracking, controllers, gaze, locomotion, comfort
- Performance profiling for mobile/standalone headsets (frame budgets, batching)
- Programming proficiency (C# or C++) and Git
- AR-specific concepts: plane detection, anchors, SLAM, occlusion
- Optional: WebXR, computer vision basics, networking for multiplayer XR

## Sub-roles / Specializations
- VR Application / Game Developer
- AR Mobile Developer (ARKit / ARCore)
- WebXR Developer
- XR Interaction / UX Engineer
- 3D Technical Artist / Shader Developer
- Enterprise & Industrial XR Developer (training, simulation, digital twins)
- XR Tools / SDK Engineer

## Salary Trend
US (USD): entry ~$75K–$100K, mid ~$100K–$140K, senior ~$140K–$190K+ (specialized XR/graphics roles higher). India (₹ LPA): entry ~₹5–10 LPA, mid ~₹12–22 LPA, senior ~₹25–45+ LPA. 2025–2026 demand is moderate and uneven: consumer VR is steady while enterprise/industrial XR (training, simulation, healthcare) and spatial-computing platforms drive growth; cross-skilling with general game/3D engine work improves resilience.

## Learning Roadmap
**Beginner:** Learn a 3D engine (Unity recommended) and core 3D math. Build simple 3D scenes, then a basic VR scene using OpenXR / XR Interaction Toolkit on an emulator or headset.

**Intermediate:** Implement interaction systems (grab, locomotion, UI), build a mobile AR app with ARCore/ARKit, manage the asset pipeline, and profile/optimize for standalone headsets.

**Advanced:** Master performance budgets, custom shaders, multiplayer/networked XR, advanced AR (occlusion, persistent anchors), and platform-specific publishing for stores and enterprise deployment.

## Notes for Course Generation
Build the course around a single immersive project iteratively expanded (3D scene → VR interaction → AR variant), since hands-on engine practice is essential. Make performance and comfort optimization a recurring theme because poor frame rates cause real user harm. Default to Unity for its lower entry barrier and large learning ecosystem, noting Unreal as the higher-fidelity alternative.
